# Bonolo Mogorosi — Personal Portfolio

## Description

This project is a personal portfolio website created to showcase my skills, education, projects and interests as an Information Technology student specialising in System Development.

The website was designed and developed using HTML5, CSS3 and JavaScript. It provides information about my background, technical skills, education, projects and contact details.

## Technologies Used

- JavaScript
- Visual Studio Code
- Git
- GitHub
- GitHub Pages

## Features

- Responsive portfolio layout
- Home/Introduction section
- About Me section
- Skills section
- Projects section
- Education section
- Contact section
- Contact form validation
- JavaScript confirmation message after submitting the contact form
- Responsive styling for smaller screen sizes
- Navigation links between portfolio sections

## How to Run the Project Locally

1. Download or clone the repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in a web browser.
4. The website can be viewed and tested locally.

## JavaScript Feature

JavaScript is used in the contact form to prevent the page from refreshing when the form is submitted and to display a confirmation message to the user.
